## 1. 절대 규칙 (확정)

1. **색상 hex 값을 컴포넌트에 직접 쓰지 않는다.** `@hr/tokens`의 `colors`만 쓴다.
   토큰에 없는 색이 필요하면 코드를 쓰지 말고 사람에게 묻는다.
2. **여백 숫자를 임의로 정하지 않는다.** `spacing` 토큰을 쓴다.
3. **새 UI 컴포넌트를 즉석에서 만들지 않는다.** `src/components`의 기존 컴포넌트를 조합한다.
   없으면 만들기 전에 사람에게 묻는다.
4. **모든 사용자 대상 문구는 해요체.** "신청되었습니다" (X) → "신청했어요" (O)
5. **그림자(shadow/elevation), 그라디언트를 쓰지 않는다.**
6. **한 화면에 Primary 버튼은 1개, 그린이 등장하는 지점은 2곳 이하.**
